# Ameer — A Digital Future

Ameer Marwan’s interactive portfolio: a home for his coding journey, experiments, and ideas for the web.

🌐 **Visit the live website:** https://ameer-marwan-code.ameer-prince.chatgpt.site

## Explore

- **Home** — animated introduction, interactive page search, and a journey through Ameer’s creative process.
- **About Me** — Ameer’s story and timeline.
- **Achievements** — Ameer’s participation in the 2026 NASA Space Apps Challenge.
- **My Programs** — interactive Hello World, live clock, and color lab demos.
- **My Websites** — portfolio showcase and a place for future creations.

## Interactive features

- Prince AI, a built-in guide that answers questions about the website.
- Animated typing, scroll reveals, and page progress.
- Dark and light themes, responsive navigation, and reduced-motion support.
- GitHub profile: [@ameer-marwan](https://github.com/ameer-marwan)

## Built with

Static HTML, CSS, and vanilla JavaScript. No build step is required.

## Run locally

Open `index.html` in your browser, or serve this folder with any static file server.
